# Fundamentos de Programação: Além dos Conceitos Básicos

## Sobre o curso

Curso da série **Fundamentos de Programação**, ministrado por **Natalia Corea**, com foco no aprofundamento dos conceitos essenciais da programação utilizando **Python**.

O conteúdo aborda conceitos intermediários e avançados que ajudam a desenvolver um repertório mais completo para quem está seguindo sua jornada na programação.

## Conteúdos abordados

* Coleções e loops
* Manipulação e combinação de strings
* Uso de códigos externos
* Estilos e boas práticas de código
* Processos essenciais de programação
* Técnicas de depuração (debugging)
* Conceitos intermediários e avançados em Python

## Objetivo

Aprofundar os conhecimentos básicos de programação e desenvolver práticas que podem ser aplicadas independentemente da linguagem utilizada.

**Instrutora:** Natalia Corea  
**Linguagem utilizada:** Python
